\# ⭐ Step Label



\## English



Step Label is a decorative node for ComfyUI Workflow Decorations.



It helps organize complex workflows into clear visual steps, making it easier to understand the workflow at a glance.



\---



\## ✨ Features



\- 🔢 STEP number

\- 📝 Step title

\- 🖼️ Icon selection

\- ✏️ Custom icon

\- 🎨 8 workflow colors

\- ⚙️ Show / hide settings UI

\- 🔒 Settings are preserved when the UI is hidden

\- 👀 Step-based visual organization



\---



\# 🚀 Usage



\## 1. Add Step Label



In ComfyUI, right-click the workspace and search for:



Step Label



Then add:



⭐ Step Label



to your workflow.

\# ⚙️ Show / Hide Settings



Step Label is designed so that its settings can normally be hidden.



\## Show Settings



Right-click the Step Label and select:



⚙️ Show Settings



The configuration UI will appear.



\---



\## Hide Settings



Right-click the Step Label and select:



⚙️ Hide Settings



The configuration UI will be hidden.



\---



\## 🔒 Settings Are Preserved



Hiding the settings UI does not reset the values.



The following settings remain unchanged:



\- STEP number

\- Title

\- Icon

\- Custom icon

\- Color



This allows you to configure the label first and then hide the settings UI to keep the workflow clean.

\---



\# 🎨 Design



Step Label uses a tab-style design.



The design consists of three main elements:



\- STEP tab

\- Accent line

\- Dark card



The STEP number and icon are displayed in the top tab.



The title is displayed in the dark card area.



The selected workflow color is applied to the tab and accent line.



The design is intentionally kept clean so that it does not interfere with the workflow itself.



\---



\# 🧩 Purpose



Step Label does not perform image generation or processing.



It is a decorative node designed to organize and visually explain a ComfyUI workflow.



The goal is to make workflows easier to:



See  

↓  

Understand  

↓  

Use



rather than requiring users to read every node individually.

\- カスタムアイコン

\- カラー



つまり、

\# 🎨 デザイン



Step Labelはタブ風のデザインを採用しています。



主な構成は、



\- STEPタブ

\- アクセントライン

\- ダークカード



の3要素です。



上部のタブ部分にSTEP番号とアイコンを表示し、ダークカード部分にタイトルを表示します。



選択した工程カラーは、タブとアクセントラインに反映されます。



ワークフローの邪魔にならないよう、シンプルで見やすいデザインを重視しています。



\---



\# 🧩 Step Labelの役割



Step Labelは、画像生成や画像加工そのものを行うノードではありません。



ComfyUIワークフローを整理し、工程を視覚的に分かりやすくするための装飾ノードです。



目的は、



見る  

↓  

理解する  

↓  

使う



という流れを作ることです。
