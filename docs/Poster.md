\# Poster Node



\## Overview



Poster Node is a display-only node for placing images directly into a ComfyUI workflow.



It is designed for workflow documentation, reference images, character sheets, notes, and previews.



\---



\# Features



\- Image display

\- Change image

\- Delete image

\- Save and restore image state

\- Aspect ratio preserving resize

\- Hidden title bar

\- Clean minimal display



\---



\# Operations



\## Change Image



Right-click the Poster node and select:



Change Image



Select an image file to display it.



\---



\## Delete Image



Right-click the Poster node and select:



Delete Image



The current image will be removed and the Poster node returns to the empty state.



\---



\# Resize



Poster supports resizing while maintaining the original image aspect ratio.



This prevents image distortion during node resizing.



\---



\# Save and Restore



The displayed image information is saved with the workflow.



When reopening the workflow, the Poster image will be restored.



\---



\# Display Style



Poster is designed as a minimal workflow decoration node.



Features:



\- No title bar

\- Image-focused display

\- Simple workflow presentation
