# 🎨 ComfyUI Workflow Decorations

# ✨ Features

## 🖼️ Poster Node

A display-only node for placing images directly into a ComfyUI workflow.

Useful for:

- Workflow documentation
- Reference images
- Character sheets
- Configuration notes
- Preview images

### Features

- Image display
- Change image
- Delete image
- Save and restore image state
- Aspect ratio preserving resize
- Hidden title bar
- Clean minimal display

📖 [Poster Documentation](docs/Poster.md)

---

## ⭐ Step Label

A decorative node for organizing ComfyUI workflows into clear and readable steps.

Useful for:

- Workflow organization
- Process visualization
- Section separation
- Generation pipeline explanation

### Features

- STEP number
- Step title
- Icon selection
- Custom emoji icon
- 8 workflow colors
- Show / hide settings UI
- Settings preservation
- Tab-style visual design

📖 [Step Label Documentation](docs/StepLabel.md)

---

# ⚙️ Display Settings

## Hide Node Source Badge

ComfyUI can display node source labels such as:

`WorkflowDecorations`

These labels can be hidden using ComfyUI's standard settings.

### Settings

**Settings**

↓

**Lite Graph**

↓

**Node Source Badge Mode**

↓

**None**

After changing this setting, node source labels will be hidden.

> This setting applies globally to ComfyUI.
